# 📖 Шпаргалка D01 · D02

Простой сайт-мануал: пошаговые инструкции по квестам **D01T01 (Linux и Git)** и **D02T02 (первая программа на C)**.
Делай задание, глядя на сайт — шаг за шагом.

## Как открыть

Просто открой файл `index.html` в браузере (двойной клик). Сервер не нужен — весь сайт в одном файле.

Или через локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
